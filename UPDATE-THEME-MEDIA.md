# Обновление личного кабинета: полноэкранное кино + впечатления + темы

1. В Supabase проекта личного кабинета откройте SQL Editor → New query.
2. Выполните `supabase-update-theme-media.sql`. Должно появиться `Success. No rows returned`.
3. На GitHub замените файлы `index.html`, `style.css`, `app.js`, `service-worker.js`.
4. Сделайте Commit changes и дождитесь публикации GitHub Pages.
5. Полностью закройте приложение/вкладку на телефоне и откройте заново.

Что изменилось:
- карточка фильма/сериала открывается почти на весь экран на компьютере и на весь экран телефона;
- содержимое карточки прокручивается внутри окна, а кнопки сохранения остаются внизу;
- отдельные поля «Заметки» и «Мои впечатления»;
- 5 тем кабинета: Лаванда, Роза, Океан, Шалфей, Персик;
- выбранная тема сохраняется в Supabase и синхронизируется между устройствами.
