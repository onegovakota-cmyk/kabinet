# v7 — единая вкладка «Финансы»

Изменения:
- Долги, Доходы и Расходы объединены в «Финансы».
- Внутри: Обзор / Доходы / Расходы / Долги.
- Показываются доходы, расходы, платежи по долгам и свободный остаток за месяц.
- Доход можно отметить как «На карту» или «Наличными».
- На обзоре отдельно видны поступления на карту и наличными.

Установка:
1. В Supabase личного кабинета запустите `supabase-update-finance-v7.sql`.
2. На GitHub замените `index.html`, `style.css`, `app.js`, `service-worker.js`.
3. Нажмите Commit changes и дождитесь GitHub Pages.
4. Полностью перезапустите приложение на телефоне.
