# Мой личный кабинет

Личное веб-приложение на HTML/CSS/JS + Supabase + GitHub Pages.

## Разделы

- **Главная:** доходы, расходы, платежи по долгам, свободный остаток + быстрый обзор чтения, кино, настроения и сна.
- **Долги:** автокредит, кредитная карта, кредит на учёбу; прогресс, целевой платёж, редактирование остатка, история платежей.
- **Доходы:** источники и история поступлений.
- **Расходы:** фактические траты и постоянные расходы.
- **Привычки:** свои привычки, отметки на каждый день месяца, прогресс.
- **Задачи:** Работа / Репетиторство / Домашние дела.
- **Книги:** читаю / хочу прочитать / прочитано / отложено, купленные и любимые книги, обложки, страницы, оценки, заметки, дневник чтения, таймер, календарь, серия дней и годовая цель.
- **Фильмы и сериалы:** список желаний, смотрю, просмотрено, брошено, оценки, избранное, прогресс сериалов и случайный выбор из списка желаний.
- **Настроение:** отметка 1–5 на каждый день, заметки, календарь и статистика месяца.
- **Сон:** время сна и подъёма, автоматическая длительность, качество сна, календарь и средние показатели.
- **Настройки:** средний доход, книжная цель на год, цель чтения в день и цель сна.
- **Вход:** email + пароль через Supabase Auth.
- **PWA:** сайт можно добавить на главный экран телефона.

## Если приложение уже установлено

Сначала запустите в Supabase файл `supabase-update-life.sql`.
Он добавляет только новые таблицы и настройки и не удаляет старые финансовые данные.

После успешного `Success. No rows returned` замените на GitHub:
- `index.html`
- `style.css`
- `app.js`
- `service-worker.js`
- `manifest.webmanifest`

`config.js` менять не нужно.

После публикации полностью закройте приложение на телефоне и откройте снова. Версия кэша повышена, поэтому новая версия должна загрузиться автоматически.

## Чистая установка

Для нового проекта можно запустить полный `supabase.sql`, затем загрузить все файлы на GitHub Pages.
