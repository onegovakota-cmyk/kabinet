# v8 — формат книги

Добавлено:
- 📖 Бумажная книга
- 📱 Электронная книга
- 🎧 Аудиокнига

Формат выбирается в карточке книги и отображается в библиотеке.
У старых книг формат остаётся «не указан» в базе до следующего редактирования.

Установка:
1. В Supabase личного кабинета запустите `supabase-update-book-format-v8.sql`.
2. На GitHub замените:
   - index.html
   - style.css
   - app.js
   - service-worker.js
3. Commit changes и дождитесь GitHub Pages.
4. Полностью перезапустите приложение на телефоне.
