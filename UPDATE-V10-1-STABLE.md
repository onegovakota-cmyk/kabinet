# v10.1 — стабильное обновление + исправление доходов

## Почему не добавлялся доход
Текущий интерфейс сохраняет способ получения дохода:
- `card` — на карту
- `cash` — наличными

Если в таблице `pf_incomes` ещё нет колонки `income_method` или отсутствует RLS-политика на INSERT,
Supabase отклоняет запись целиком.

## Что делает v10.1
- чинит добавление доходов;
- проверяет/создаёт `income_method`;
- восстанавливает RLS для таблицы доходов;
- приложение умеет временно сохранить доход даже со старой схемой;
- при настоящей ошибке теперь показывается текст ошибки Supabase;
- включает все разделы v10 Life OS:
  - Сегодня
  - Финансы
  - Привычки
  - Задачи
  - Планирование: цели / проекты / мой месяц / обзор недели / Inbox
  - Книги
  - Кино
  - Настроение
  - Сон
  - Состояние: энергия / стресс / самочувствие / колесо жизни
  - Развитие / курсы
  - Итоги / достижения / мой год

## Установка
1. Откройте Supabase именно проекта личного кабинета.
2. SQL Editor → New query.
3. Запустите весь файл `supabase-repair-v10-1.sql`.
4. Дождитесь `Success. No rows returned`.
5. На GitHub замените:
   - `index.html`
   - `style.css`
   - `app.js`
   - `service-worker.js`
6. Commit changes.
7. Дождитесь зелёной галочки GitHub Pages.
8. На телефоне полностью закройте сайт/PWA и откройте заново.

Старые пользовательские данные этот SQL не удаляет.
