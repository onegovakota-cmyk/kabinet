# v10.4 — горящие проекты на главной

На экране «Сегодня» добавлен блок «🔥 Горящие проекты».

Показываются только проекты:
- со статусом «В работе»;
- у которых есть дедлайн;
- дедлайн уже просрочен или наступит в ближайшие 7 дней.

Для каждого проекта показываются:
- название;
- направление;
- дата дедлайна;
- сколько дней осталось / сколько дней просрочено;
- прогресс;
- выполненные этапы;
- кнопка «Открыть».

Если срочных проектов нет, показывается спокойное сообщение «Горящих дедлайнов нет ✨».

Supabase и SQL менять не нужно.

На GitHub замените:
1. index.html
2. style.css
3. app.js
4. service-worker.js

После Commit changes дождитесь GitHub Pages и полностью перезапустите приложение.
